## Detailed Notes

### Project Presentations Overview
- Students presented projects focused on data analysis and machine learning applications related to customer feedback.

### Key Project: Field Notes Desk
- **Objective**: Analyze Amazon reviews to derive actionable insights for business decisions.
- **Data Handling**:
  - Utilized datasets with approximately 30,000 rows of Amazon reviews.
  - Cleaned and deduplicated data to identify 60 unique products and create six product categories.

### Methodologies and Tools Used
1. **Sentiment Analysis**:
   - Employed a distilled BERT model for sentiment classification.
   - Addressed class imbalance by under-sampling and applying class weights.

2. **Product Clustering**:
   - Used TF-IDF for word embeddings and K-means for clustering.
   - Silhouette score determined the optimal number of clusters (6).

3. **Data Cleaning**:
   - Merged overlapping definitions and cleaned unreliable product ID fields.
   - Grouped reviews into semantic levels and generated readable summaries.

4. **Model Deployment**:
   - Organized models to produce category-level statistics for summarization.
   - Fine-tuned and sanitized the distilled BERT model post-training.

### Challenges Encountered
- Issues with unreliable product IDs and initial clustering results prompted adjustments in input features.

### Conclusion
- The project successfully integrated various machine learning techniques to analyze and summarize Amazon reviews, providing a framework for informed business decisions.

### Clustering and Data Enrichment
- Initial clustering based on product names was ineffective; combining product names with subcategories improved clarity.

### Data Organization
- Sentiment analysis results and clustering data were organized into JSON files for generative AI models.

### Model Deployment Challenges
- Deployment issues arose due to model size, even after quantization.

### Sentiment Prediction API
- Developed a backend API to predict sentiment from reviews, returning sentiment labels and confidence scores.

### Generative Summarization
- Created a pipeline for generating summaries highlighting top products and common complaints.

### Web Application Features
- Included functionalities for review prediction and category details reporting.

### Chatbot Development
- Developed two chatbot personalities: Recommender and Skeptical.

### Final Product and Deployment
- The final product utilized Next.js for the frontend and FastAPI for the backend, deployed on Confluence.

## Key Takeaways

- Choose appropriate metrics for evaluation, especially in imbalanced datasets.
- A complete pipeline (classify, cluster, summarize) is essential for transforming raw data into actionable insights.
- Generative AI should be grounded in real data to maintain reliability.
- Continuous error analysis is crucial for improving model performance.
- Effective data management and organization enhance application performance and user experience.
