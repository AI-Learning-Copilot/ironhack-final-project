## Detailed Notes

### Supervised Learning Metrics - Regression

- **Mean Absolute Error (MAE)**: 
  - Formula: \( MAE = \frac{1}{n} \sum_{i=1}^{n} |y_i - \hat{y}_i| \)
  - Measures average absolute differences; robust to outliers.

- **Mean Squared Error (MSE)**: 
  - Formula: \( MSE = \frac{1}{n} \sum_{i=1}^{n} (y_i - \hat{y}_i)^2 \)
  - Penalizes larger errors; sensitive to outliers.

- **Root Mean Squared Error (RMSE)**: 
  - Formula: \( RMSE = \sqrt{MSE} \)
  - Provides error in the same units as the target variable; interpretable.

- **R² (Coefficient of Determination)**: 
  - Formula: \( R^2 = 1 - \frac{SS_{res}}{SS_{tot}} \)
  - Indicates the proportion of variance explained by the model; ranges from negative values to 1.

### Supervised Learning Metrics - Classification

- **Confusion Matrix**: 
  - Summarizes true positives, false positives, true negatives, and false negatives.

- **Accuracy**: 
  - Formula: \( \text{Accuracy} = \frac{TP + TN}{TP + TN + FP + FN} \)

- **Precision**: 
  - Formula: \( \text{Precision} = \frac{TP}{TP + FP} \)

- **Recall**: 
  - Formula: \( \text{Recall} = \frac{TP}{TP + FN} \)

- **F1-Score**: 
  - Formula: \( F1 = 2 \cdot \frac{\text{Precision} \times \text{Recall}}{\text{Precision} + \text{Recall}} \)

### Supervised Learning Algorithms - Classification

1. **Logistic Regression**: 
   - Fits a sigmoid curve to predict class probabilities.

2. **KNN Classifier**: 
   - Classifies based on the majority class of K nearest neighbors.

3. **Decision Tree Classifier**: 
   - Splits data recursively based on feature thresholds.

4. **Random Forest Classifier**: 
   - An ensemble of decision trees that averages predictions.

5. **Support Vector Machines (SVM)**: 
   - Finds the hyperplane that maximizes the margin between classes.

6. **Naive Bayes**: 
   - A probabilistic model assuming feature independence.

### Supervised Learning Algorithms - Regression

1. **Linear Regression**: 
   - Fits a straight line to minimize squared errors.

2. **Polynomial Regression**: 
   - Extends linear regression with polynomial features.

3. **Ridge Regression (L2)**: 
   - Adds a penalty on the sum of squared weights.

4. **Lasso Regression (L1)**: 
   - Adds a penalty on the sum of absolute weights; can shrink coefficients to zero.

5. **ElasticNet**: 
   - Combines Ridge and Lasso penalties.

6. **KNN Regressor**: 
   - Predicts by averaging target values of K nearest neighbors.

7. **Decision Tree Regressor**: 
   - Splits data recursively and predicts mean target values.

8. **Random Forest Regressor**: 
   - Builds multiple decorrelated decision trees and averages predictions.

9. **Support Vector Regression (SVR)**: 
   - Fits data within a margin; effective for small datasets.

10. **Neural Networks**: 
    - Composed of layers of neurons; best for unstructured data.

## Examples & Applications

- **California Housing Dataset**: Used for training a Linear Regression model to predict median house values.
- **Titanic Dataset**: Used for training a Logistic Regression model to predict passenger survival, with evaluation through confusion matrix and various metrics.
