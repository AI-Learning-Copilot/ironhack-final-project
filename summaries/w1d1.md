- **Artificial Intelligence (AI)**: Systems that mimic human intelligence, encompassing machine learning and deep learning.
- **Machine Learning (ML)**: Algorithms that enable systems to learn from data.
- **Deep Learning (DL)**: A subset of ML using neural networks with multiple layers.

## Detailed Notes

### Introduction to AI Engineering
- **AI Definition**: A branch of computer science focused on creating systems that perform tasks requiring human intelligence.
- **Subfields**:
  - **Machine Learning (ML)**: Algorithms that learn from data.
  - **Deep Learning (DL)**: Uses neural networks to model complex patterns.
  - **Expert Systems**: Simple AI using hard-coded rules for decision-making.

### Python Fundamentals
- **Command Line Basics**:
  - `pwd`: Prints the current working directory.
  - `ls`: Lists directory contents; variants include `ls -a` (hidden files) and `ls -l` (detailed info).
  - `mkdir`: Creates a new directory.
  - `cd`: Changes the current directory.
  
- **For Loop**: Iterates over a sequence, useful for displaying items in a list with their positions.
- **Enumerate**: Allows tracking of indices while iterating through a list.

### Git Introduction
- **Version Control**: Git tracks changes in files, enabling collaboration and version management.
- **Key Commands**:
  - `git init`: Initializes a new Git repository.
  - `git status`: Checks the current status of the repository.
  - `git add <filename>`: Stages files for commit.
  - `git commit -m "message"`: Commits changes with a descriptive message.
  - `git push`: Sends committed changes to a remote repository.

### Jupyter Notebooks
- **Importance**: Essential for data science and AI projects, allowing interactive coding and visualization.
- **Usage**: Supports Markdown for documentation, enabling structured explanations alongside code.
