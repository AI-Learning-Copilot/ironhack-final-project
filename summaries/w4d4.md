## Overview

This lesson focuses on initiating Project 2, which involves building a classifier for an NLP challenge centered around fake news detection. Students will work with two datasets: a training dataset for model development and a validation dataset for making predictions.

## Key Concepts

1. **Dataset Structure**:
   - Two CSV files:
     - **Label**: Indicates if the news is fake (0) or real (1).
     - **Title**: Headline of the news article.
     - **Text**: Content of the news article.
     - **Subject**: Category of the news.
     - **Date**: Publication date.
   - The validation dataset lacks labels for testing model predictions.

2. **Feature Selection**:
   - Identify relevant features that significantly contribute to model performance.

3. **Classifier Development**:
   - Build a classifier to distinguish between fake and real news, making predictions on the inference dataset.

4. **Embeddings**:
   - Numerical representations of words, phrases, or sentences that capture semantic meaning.

5. **Modeling Techniques**:
   - Suggested algorithms include Logistic Regression, Naive Bayes, and Support Vector Machines (SVM).

## Detailed Notes

### Data Preparation

1. **Data Splitting**:
   - Split the dataset into training and test sets, or into three sets (training, validation, test) if sufficient data is available.
   - Use stratified sampling to maintain class proportions.

2. **Exploratory Data Analysis (EDA)**:
   - Check for class balance; if imbalanced, consider strategies to address this.

3. **Text Preprocessing**:
   - Common steps include:
     - Tokenization
     - Lowercasing
     - Removing punctuation and special characters
     - Stop word removal
     - Stemming or lemmatization

### Feature Extraction Techniques

1. **Bag-of-Words (BoW)**: Represents text data by counting word frequency.
2. **Term Frequency-Inverse Document Frequency (TF-IDF)**: Reflects the importance of a word in a document relative to a collection.
3. **N-grams**: Captures sequences of words (e.g., bigrams).
4. **Word Embeddings**: Techniques like GloVe provide dense vector representations of words.

### Model Selection

- Recommended algorithms:
  - **Logistic Regression**: Baseline model.
  - **Naive Bayes**: Effective for text classification.
  - **Support Vector Machines (SVM)**: Finds the optimal hyperplane for class separation.

### Model Training and Evaluation

- Evaluate model performance using appropriate metrics.
- Perform hyperparameter tuning to optimize results.

### Implementation Details

- **Accessing Notebooks**: Use Visual Studio Code Online or clone the repository if Jupyter notebooks cannot be opened.
- **CSV File Handling**: Use extensions like Rainbow CSV for better readability.
- **Computational Considerations**: Training models with embeddings may require significant resources.

## Examples & Applications

- **Predicting Fake News**: Analyze sentences like "Vatican won the World Cup" to determine veracity using embeddings and classification techniques.
- **Document and Sentence Embeddings**: Use techniques like Doc2Vec for entire documents, requiring training on specific datasets.
