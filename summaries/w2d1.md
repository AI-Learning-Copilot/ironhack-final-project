## Overview

This lesson introduces the foundational concepts of Artificial Intelligence (AI) and Machine Learning (ML), focusing on supervised learning techniques, specifically linear and logistic regression. It includes practical demonstrations and labs using real-world datasets.

## Key Concepts

- **Supervised Learning**: Training models on labeled data to make predictions.
- **Linear Regression**: Predicting continuous outcomes based on input features.
- **Logistic Regression**: Predicting binary outcomes (classification).
- **Data Preprocessing**: Cleaning and preparing data for model training.
- **Model Evaluation**: Assessing model performance using various metrics.

## Detailed Notes

### 1. Linear Regression with California Housing Dataset

- **Objective**: Predict the median house value in California districts.
- **Dataset Features**:
  - `MedInc`, `HouseAge`, `AveRooms`, `AveBedrms`, `Population`, `AveOccup`, `Latitude`, `Longitude`
  - **Target Variable**: `MedHouseVal` (median house value in $100,000s)
- **Key Concepts**:
  - Continuous target variable.
  - Use of median to reduce outlier influence.
- **Workflow**:
  1. Load dataset using `fetch_california_housing()`.
  2. Create a DataFrame for manipulation.
  3. Conduct Exploratory Data Analysis (EDA).

### 2. Logistic Regression with Titanic Dataset

- **Objective**: Predict passenger survival on the Titanic.
- **Dataset Features**:
  - `survived`, `pclass`, `sex`, `age`, `sibsp`, `parch`, `fare`, `embarked`
- **Key Concepts**:
  - Binary classification problem.
  - Importance of data cleaning and encoding categorical variables.
- **Workflow**:
  1. Load dataset using `sns.load_dataset('titanic')`.
  2. Perform EDA to understand data structure and distribution.
  3. Check for class imbalance.

### 3. Exploratory Data Analysis (EDA)

- **Purpose**: Understand dataset structure and identify issues.
- **Tools Used**: Pandas for data manipulation; Seaborn and Matplotlib for visualization.
- **Key Steps**:
  - Check data types and missing values.
  - Analyze feature distributions and visualize relationships.

### 4. Data Handling

- **Missing Values**: Identify and handle using `df.isnull().sum()`.
- **Data Cleaning**: Drop columns or rows with significant missing data.
- **Encoding Categorical Variables**: Use `pd.get_dummies()` to convert categorical features to numeric.

### 5. Model Training and Evaluation

- **Train-Test Split**: Commonly 80% train / 20% test using `train_test_split`.
- **Model Evaluation**:
  - Use R² for regression models.
  - Use accuracy and confusion matrix for classification models.
- **Overfitting vs. Underfitting**:
  - Underfitting: Model too simple.
  - Overfitting: Model too complex, memorizing training data.

## Examples & Applications

- **Linear Regression**: Demonstrated using the California Housing Dataset to predict housing prices.
- **Logistic Regression**: Applied to the Titanic dataset to classify survival outcomes.
- **Hands-on Labs**: Students practice data cleaning, model training, and evaluation using provided datasets.

## Key Takeaways

- Supervised learning involves training models on labeled data.
- Linear regression predicts continuous outcomes, while logistic regression is used for binary classification.
- Data preprocessing is crucial for model accuracy, including handling missing values and encoding categorical variables.
- Model evaluation metrics vary by task; R² for regression and accuracy/confusion matrix for classification.
- Understanding overfitting and underfitting is essential for developing robust models.
