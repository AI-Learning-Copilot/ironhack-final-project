# W2D5 — IronKaggle Intro

> Study notes generated from the indexed Ironhack AI Engineering course recordings and notebooks.

## Overview

In this lesson, students participate in a machine learning challenge inspired by Kaggle competitions, focusing on predicting sales for shops using provided datasets.

## Key Concepts

1. **Kaggle Competitions**: 
   - A platform for machine learning challenges where participants develop models to achieve the best performance based on specific metrics.

2. **Dataset Structure**:
   - **Labeled Dataset**: Contains features and the target variable (sales) for training.
   - **Inference Dataset**: Contains only features without labels for making predictions.

3. **Data Preparation**:
   - Understand data, perform cleaning, and choose a data splitting strategy:
     - Train-Test Split
     - Train-Test with Cross-Validation
     - Train-Validation-Test Split
   - Cross-validation is useful with limited data.

4. **Model Training and Evaluation**:
   - Train models and evaluate using the R-squared metric, which measures the variance explained by the independent variables.

5. **Submission Process**:
   - Apply trained models to the inference dataset to generate predictions.
   - Predictions should be added as a new column in the inference dataset.
   - Final submission deadline is at 5 PM; late submissions are not accepted.

## Detailed Notes

### Workflow Summary
1. Receive and explore the labeled dataset.
2. Clean and preprocess the data.
3. Split the data using a chosen strategy.
4. Train models and evaluate performance using R-squared.
5. Apply the best-performing model to the inference dataset.
6. Add predictions to the inference dataset and submit by the deadline.

### Submission Requirements
- **Deadline**: All submissions must be made by 5 PM; late submissions will not be accepted.
- **Submission Format**:
  - Git repository with notebooks or Python scripts (notebooks preferred).
  - A CSV file named `group_<your_number>.csv` with the inference dataset and a new `sales` column for predictions.
  - A `.txt` file named `group.<your_number>.txt` with the R² score calculated on the test set.

### Data Preprocessing and Data Leakage
- **Data Leakage**: Avoid using information from the test set during training.
  - Fit preprocessing steps only on the training set.
  - Transform the test set without fitting to ensure accurate evaluation.

### Preprocessing Steps
- **Fitting and Transforming**:
  - Fit preprocessing techniques (e.g., `StandardScaler`) only on the training set.
  - Use `fit_transform()` on the training set and `transform()` on validation, test, and inference datasets.

### Data Splitting
- Split the dataset into at least two parts (training and testing) or three parts (training, validation, and testing) to facilitate proper evaluation and avoid data leakage.

### Group Collaboration
- Students work in groups, with options to collaborate or split into pairs.
- Recommended to start from one computer to avoid file conflicts.

### Tools and Resources
- Utilize tools like Claude, Chachi, and Bitbucket.
- Attempt to resolve issues using available resources before seeking help.

### Project Goals
- Develop a model to achieve the highest R-squared score on the test set.
- The exercise aims to provide a realistic environment for practicing learned concepts.

### Breakout Rooms

## Examples & Applications

- **Fitting the Scaler**: Always fit the scaler on the training set only.
- **Applying the Scaler**: Use the fitted scaler to transform validation, test, and inference datasets.
- **Creating Reusable Functions**: Define functions for preprocessing steps to avoid code duplication.
- **Using Pickle**: Save scalers and models using `pickle` for reuse in different contexts.
- **Exploring Pipelines**: Consider using scikit-learn pipelines for a more efficient workflow.

## Key Takeaways
- Adhere to submission deadlines and requirements.
- Prevent data leakage by fitting preprocessing steps only on the training set.
- Apply consistent preprocessing across all datasets.
- Collaborate effectively within groups and utilize available tools.
- Focus on achieving the highest R-squared score for the challenge.
