## Overview

This lesson introduces LangChain, a framework for building applications that utilize Large Language Models (LLMs). It covers environment setup, the LangChain Expression Language (LCEL), chains, prompt templates, and practical applications through labs.

## Key Concepts

- **LangChain**: A framework for creating AI workflows by chaining components like prompts, models, and data retrieval systems.
- **Virtual Environments**: Recommended for managing dependencies and ensuring compatibility with LangChain versions below 0.3.
- **LangChain Expression Language (LCEL)**: A minimalist code layer for building chains of LangChain components using the pipe operator (`|`).
- **Chains**: Sequences that manage data flow, connecting various components to automate processes.
- **Prompt Templates**: Reusable structures for generating prompts with dynamic inputs.
- **Runnables**: Components that allow for flexible data processing and chaining of functions.

## Detailed Notes

### Environment Setup

- **Creating a Virtual Environment**:
  ```bash
  python -m venv .venv/langchain-v0.2.x
  ```
- **Activating the Environment**:
  - macOS / Linux:
    ```bash
    source .venv/langchain-v0.2.x/bin/activate
    ```
  - Windows (PowerShell):
    ```powershell
    .\.venv\langchain-v0.2.x\Scripts\Activate.ps1
    ```
- **Installing Required Packages**:
  ```bash
  python -m pip install \
  "langchain<0.3" \
  "langchain-core<0.3" \
  "langchain-community<0.3" \
  "langchain-openai<0.2" \
  ipykernel
  ```
- **Registering the Environment as a Jupyter Kernel**:
  ```bash
  python -m ipykernel install \
  --user \
  --name langchain-v0.2.x \
  --display-name "Python (LangChain 0.2.x)"
  ```

### LangChain Expression Language (LCEL)

- **Definition**: An abstraction for building chains using a minimalist syntax.
- **Pipe Operator**: Used to chain components, e.g., `lcel_chain = prompt | model | output_parser`.
- **Runnables**: Custom classes that allow chaining of functions using the pipe operator.

### Chains in LangChain

- **Types of Chains**:
  - **LLMChain**: Connects a prompt template to an LLM.
  - **SequentialChain**: Combines multiple chains where the output of one serves as the input for the next.
  - **RunnableParallel**: Executes multiple operations in parallel.
  - **MapReduceDocumentsChain**: Processes large document sets using a map-reduce approach.

### Prompts and Prompt Templates

- **Prompt**: Instruction given to a model to elicit specific output.
- **Prompt Template**: A reusable prompt structure with placeholders for dynamic input.
- **Creating Prompt Templates**:
  - Using `from_template()` for automatic inference of input variables.
  - Explicit constructor for manual definition.

### Important Implementation Details

- **Environment Variables**: Use `.env` files to manage API keys securely.
- **Model Configuration**: Adjust parameters like `temperature` for output variability.
- **Output Parsing**: Use output parsers like `StrOutputParser` for formatting.

## Examples & Applications

- **Example of SequentialChain**:
  - Generate text based on a topic and then translate it.
- **LLMMathChain**: Translates natural language math questions into Python code for evaluation.
- **TransformChain**: Cleans input data before processing.

## Key Takeaways

- LangChain facilitates the creation of complex AI workflows by chaining components.
- Setting up a virtual environment is crucial for managing dependencies.
- LCEL allows for concise chaining of operations using the pipe operator.
- Prompt templates enhance the scalability and maintainability of prompts.
- Understanding chains and their types is essential for effective application development in LangChain.
