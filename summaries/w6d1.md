## Overview

This lesson focuses on deploying both the frontend and backend components of an application using Vercel and Render.com, respectively. It covers the creation of an API with FastAPI, advanced Git concepts, and addresses common deployment issues such as CORS errors.

## Key Concepts

- **Deployment Environments**: Development, staging, and production environments.
- **FastAPI**: A modern framework for building APIs in Python.
- **CORS (Cross-Origin Resource Sharing)**: A security feature that restricts web pages from making requests to a different domain.
- **Monorepository Structure**: Organizing both backend and frontend in a single repository for easier management.
- **Model Exporting**: Using libraries like Pickle or Joblib for saving trained models.

## Detailed Notes

### Deployment Overview
- **Purpose**: Make the API accessible online.
- **Platforms**: Use Render.com for backend API deployment and Vercel for frontend deployment.

### Creating an API with FastAPI
- **API Structure**: Organized in a directory with files for schema, prediction functions, and endpoints.
- **Endpoints**: Defined using `app.get` or `app.post` methods to handle requests.
- **Data Validation**: Implement validation schemas to ensure incoming requests contain expected data fields.

### Deploying the API on Render.com
- **Setup Steps**:
  1. Create an account and log in.
  2. Select "New Web Service" and choose the repository.
  3. Configure environment settings, build commands, and start commands.
  4. Monitor the deployment process for errors.

### Frontend Development
- **Frontend Creation**: Develop using static HTML initially, then transition to a React application.
- **User Interaction**: Provide a user-friendly interface for inputting data and displaying results.
- **CORS Error Handling**: Ensure the API allows requests from the frontend's domain.

### Deployment Process
- **Monorepo Structure**: Simplifies management by keeping both backend and frontend in one repository.
- **Deployment Steps**:
  1. Set up environments (dev and production).
  2. Develop the backend API using FastAPI.
  3. Create the frontend application.
  4. Deploy the backend on Render.com and the frontend on Vercel.com.

## Key Takeaways

- Understand the importance of deployment environments and their configurations.
- Familiarize with FastAPI for building APIs and defining endpoints.
- Address CORS issues to ensure proper communication between frontend and backend.
