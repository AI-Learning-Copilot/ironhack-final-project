## Detailed Notes

### Python Variables and Memory Model
- **Variable Concept**: Variables are names that point to objects in memory, not simple containers.
- **Memory Storage**: Understanding how data is stored is crucial for variable interaction.
- **Comparison**: Use `==` for value equality and `is` for identity comparison (memory address).
- **Data Types**: Python supports mutable (e.g., lists) and immutable (e.g., strings) types.

### NumPy
- **Library Overview**: NumPy stands for Numerical Python, essential for numerical operations.
- **Data Structures**: 
  - **Arrays**: Multi-dimensional structures (1D vectors, 2D matrices).
- **Functionality**: Fast mathematical operations, including linear algebra and broadcasting.
- **Installation**: Use `import numpy as np` to import the library.

### Pandas
- **Library Overview**: Essential for data manipulation and analysis.
- **Data Structures**:
  - **Series**: One-dimensional labeled arrays.
  - **DataFrame**: Two-dimensional labeled data structures, similar to spreadsheets.
- **Usage**: Important for cleaning, transforming, and exploring tabular data.
- **Installation**: Use `import pandas as pd` to import the library.

### Descriptive Statistics
- **Purpose**: Summarize and describe dataset characteristics.
- **Key Measures**:
  - **Mean**: Average value.
  - **Mode**: Most frequently occurring value.
  - **Median**: Middle value when ordered.
  - **Standard Deviation**: Variation or dispersion measure.
  - **Quartiles**: Divide data into four equal parts.

### Exploratory Data Analysis (EDA) and Data Cleaning
- **EDA**: Initial exploration to understand data structure and identify anomalies.
- **Data Cleaning**: Handling missing values and correcting data types before model training.

## Examples & Applications
- **Descriptive Statistics Example**: In a dataset of ages, the mean might be 30, the mode could be 25, and the median might be 28.
- **Pandas Usage**: Creating a DataFrame to analyze sales data, renaming columns, and performing operations like calculating the mean.
