## Overview

This lesson covers the core ideas of transformer architecture, the concept of APIs, practical examples of using the OpenAI API, and the principles of prompt engineering. It provides a foundation for understanding how to interact with AI models and design effective prompts to elicit desired responses.

## Key Concepts

- **API (Application Programming Interface)**: A mechanism for software applications to communicate, involving requests and responses.
- **Transformer Architecture**: A model architecture that uses attention mechanisms to process sequential data efficiently.
- **Prompt Engineering**: The practice of designing prompts to guide AI models in generating accurate and relevant outputs.
- **OpenAI API**: A specific API that allows interaction with OpenAI's language models.

## Detailed Notes

### Understanding APIs
- **Definition**: APIs allow different software applications to communicate by sending requests and receiving responses.
- **Endpoints**: Specific URLs for API calls (e.g., `https://api.example.com/users`).
- **HTTP Methods**:
  - `GET`: Retrieve data.
  - `POST`: Create new data.
  - `PUT/PATCH`: Update existing data.
  - `DELETE`: Remove data.
- **Authentication**: Uses API keys or tokens to verify the identity of the requester.

### Transformer Architecture - Core Ideas
- **Attention Mechanism**: Allows each token to consider other tokens in the input sequence simultaneously, improving context comprehension.
- **Self-Attention**: Each token determines which other tokens to focus on, enhancing the model's understanding of relationships.

### Prompt Engineering
- **Definition**: Crafting instructions for AI models to elicit accurate responses.
- **Tips for Effective Prompts**:
  1. Define a clear role for the model.
  2. Be explicit and specific in instructions.
  3. Provide relevant context.
  4. Avoid irrelevant information.
  5. Include examples (one-shot or few-shot).
  6. Use delimiters to separate instructions from user input.
  7. Specify output format.
  8. Give clear do's and don'ts.
  9. Test edge cases.
  10. Iterate and refine prompts.

### Using OpenAI API
- **Setup**:
  - Create a `.env` file to store the OpenAI API key securely.
  - Use the `python-dotenv` library to load environment variables.
- **Example API Call**:
  ```python
  def get_llm_response(message, system=None):
      response = client.responses.create(
          model="gpt-5.4-nano",
          instructions=system,
          input=message
      )
      print(response.output_text)
  ```

### Iterative Prompt Development
- Focus on refining prompts through analysis and testing to improve output quality.
- Use structured outputs and specify formats (e.g., JSON) for clarity.
