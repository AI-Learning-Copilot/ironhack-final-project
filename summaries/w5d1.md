5. **Grouping Results**:
   - The `GROUP BY` clause is used to arrange identical data into groups. It is often used with aggregate functions to perform calculations on each group. For example, `SELECT town, COUNT(*) FROM students GROUP BY town` counts the number of students in each town.

6. **Having Clause**:
   - The `HAVING` clause is used to filter groups based on aggregate values. It is similar to the `WHERE` clause but is applied after grouping. For example, `SELECT town, COUNT(*) FROM students GROUP BY town HAVING COUNT(*) > 5` retrieves towns with more than five students.

### Examples & Applications

- **Creating a Table**:
  ```sql
  CREATE TABLE students (
      id INTEGER PRIMARY KEY AUTOINCREMENT,
      name TEXT NOT NULL,
      email TEXT UNIQUE NOT NULL,
      age INTEGER,
      score REAL DEFAULT 0.0
  );
  ```

- **Inserting Data**:
  ```sql
  INSERT INTO students (name, email, age, score) VALUES ('Alice', 'alice@example.com', 22, 85.5);
  ```

- **Querying Data**:
  ```sql
  SELECT * FROM students WHERE age > 20 ORDER BY score DESC LIMIT 5;
  ```

- **Using Joins**:
  ```sql
  SELECT students.name, orders.amount
  FROM students
  INNER JOIN orders ON students.id = orders.student_id;
  ```

### Key Takeaways

- SQLite is a lightweight, serverless relational database management system.
- CRUD operations (Create, Read, Update, Delete) are fundamental for database management.
- Understanding table relationships (one-to-many, many-to-many) is crucial for effective database design.
- SQL joins (Inner, Left, Right, Full Outer) allow for combining data from multiple tables.
- Use aggregate functions and the `GROUP BY` clause to perform calculations on grouped data.
- Always ensure data integrity through the use of primary and foreign keys.
- Practice with SQL commands and database management tools to reinforce learning and application skills.
